# JKFixHub

JKFixHub is a simple website idea for a local worker marketplace.

## Concept
- Customers can find workers for service categories like electricians, heater repair, and washing machine repair.
- Workers can register themselves and appear in the platform.
- No login page is required for the initial overview version.
- The design is kept simple, modern, and visually attractive for presenting the idea to people.
